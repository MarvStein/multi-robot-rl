# Multi-Robot RL

Welcome to the **multi-robot-rl** documentation. This project provides reinforcement learning environments for robotic systems using the `mjlab` framework.

## Quickstart

If you have `uv` installed, sync the environment and run:

```bash
uv sync
uv run play Mjlab-Masspoint-Reach --agent zero
```
